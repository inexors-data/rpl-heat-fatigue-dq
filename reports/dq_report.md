## Главная находка: метка «UTC» в API РПЛ

API РПЛ отдаёт время начала как `2025-07-18UTC20:30:00`, но это московское время. На 720 матчах, сопоставленных с Understat, после перевода МСК→UTC среднее расхождение -2.3 мин; если поверить метке, было бы 177.7 мин (3 часа). Погода, взятая по неверному часу, отличалась бы в среднем на 2.0°C, максимум на 7.9°C.
